# Vigilante de prácticas

Comprueba las prácticas del alumnado para el panel docente: cada 2 h (y cuando el docente pulsa ⚡) lee los
repositorios con commits nuevos, les pasa el kit de la práctica y manda el resultado al panel.

- Sin datos del alumnado: cada alumno es un código (`a1`, `a2`…); la relación con su nombre solo está en el panel.
- Los kits van sin soluciones ni material del docente.
- Secretos: `PANEL_URL` y `PANEL_CLAVE` (la clave de máquina de Mis conexiones del panel).
